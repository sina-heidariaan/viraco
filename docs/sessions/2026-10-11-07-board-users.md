Decisions:
- Every link mark is normalized to `{ href }` on save and on load. TipTap also writes `title`/`class`/`target`/`rel`, and pasted links can carry any value; the backend rejects unknown attributes, and the viewer must always render `rel="noopener noreferrer nofollow" target="_blank"`.
- Edit sends only changed fields, so a parallel edit of another field is not overwritten.
